# RED:5 artwork

The app name **RED:5** was chosen by the project owner. The public repository uses `RED-5` because a colon is not suitable in a GitHub repository name.

- [Tile/logo master](assets/red5-icon.png): original generated square artwork, ivory/red wordmark with an angular crimson flight emblem.
- [Background master](assets/red5-background.png): original generated space-flight artwork, red planetary crescent and quiet dark space on the left for future interface overlays.

Both images were created with OpenAI image generation for this project on 2026-11-23 and visually reviewed. They are not extracted game artwork or screenshots and do not establish that the game is playable. No trademark clearance or exclusivity is claimed.

These files are branding masters, not a verified PS5 package. Console-specific pixel dimensions, file encoding, safe-area behavior and in-device presentation must be checked during packaging. No title installation or console configuration was changed for this artwork.

Upstream PC branding and credits remain separate. These graphics do not replace required upstream/dependency notices in a future software release.
